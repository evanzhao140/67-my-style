# Agent notes — MCVibe / Plant API

Minecraft vibration mod ("Plant API") + iPhone app ("MCVibe"). Host PC: Windows.

## Mod (Fabric 26.2, Java 25)
- Source: `mod/`. Build: `cd mod && .\gradlew.bat --no-daemon build` → `mod\build\libs\plantapi-1.0.0.jar`
- **Canonical deploy target (always): `%APPDATA%\ModrinthApp\profiles\262\mods`**
  - Use `mod\deploy.bat` (or copy the jar there directly).
  - The user plays Minecraft via the **Modrinth App**, profile **"262"** (MC 26.2, large modpack).
  - Do NOT deploy to `.minecraft\mods` — that is not the user's play path.
- Config lives in `config/plantapi.json`; all settings exposed via Mod Menu (mod id `plantapi`).

## iOS app (SwiftUI, iOS 17+, unsigned IPA via CI)
- Source: `ios/` (project generated by XcodeGen from `ios/project.yml`).
- CI: `.github/workflows/build.yml` on push → artifact `MCVibe-ipa` (sideload with Sideloadly).
- Transports: Wi-Fi (raw-socket TCP port 25666 + UDP discovery 25667) and Bluetooth (BLE GATT via the Windows bridge).

## Windows bridge (Bluetooth path)
- Source: `bridge/` (C# / .NET 10, TFM `net10.0-windows10.0.26100.0`).
- Build: `cd bridge && dotnet publish -c Release -o publish`; run: `bridge\run-bridge.bat`.
- Bridges the mod's TCP stream (127.0.0.1:25666) → BLE notifications
  (service `6D637669-6265-4D43-5649-424500000001`, characteristic `...-424500000002`; 20-byte chunked frames, header byte = (index<<1)|last).

## CI & debugging notes
- Repo: `github.com/evanzhao140/67-my-style` (public).
- `git push` from the PC exits non-zero but succeeds — verify with `git ls-remote origin refs/heads/main`.
- Failed iOS builds grep their errors into branch `build-log-out` → `build-log.txt` (read via the contents API; raw.githubusercontent can serve stale CDN cache).
- Crash symbolication: `.github/workflows/symbolize.yml` → branch `symbols-out` → `symbols.txt`.
- Swift gotcha already hit: inside a method named `connect`, call the C socket function as `Darwin.connect(...)` — the member otherwise shadows the global.
- PowerShell `Invoke-WebRequest`/`Invoke-RestMethod` stall on this PC — use `curl.exe` for downloads and API calls.
